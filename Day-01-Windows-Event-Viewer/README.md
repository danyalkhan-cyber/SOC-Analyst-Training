# Day 01 – Windows Event Viewer & Security Logs

## Objective
Learn how to investigate Windows security events using Event Viewer.

## Practical Tasks
- Opened Windows Event Viewer.
- Navigated to Windows Logs → Security.
- Filtered logs using Event ID 4625.
- Identified failed logon events.
- Examined detailed event properties.

## Key Learning
Event ID 4625 records failed logon attempts in Windows Security Logs.

## Tools Used
- Windows Event Viewer
- Windows Security Logs

## Investigation Fields
- Account Name
- Failure Reason
- Logon Type
- Workstation Name
- Source Network Address
- Time Created
